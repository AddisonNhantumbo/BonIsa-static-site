# BonIsa - Site de Beleza

Este é um site estático criado para o BonIsa, um espaço onde a beleza encontra sua essência.

## Link do site

Acesse o site online aqui: [https://bon-isa-static-site-fc4l.vercel.app](https://bon-isa-static-site-fc4l.vercel.app)

## Estrutura do Projeto

- HTML e CSS puros
- Layout simples com seções:
  - Bem-vindo
  - Sobre Nós
  - Contato (WhatsApp, Facebook, Instagram)

## Deploy

O site está hospedado na [Vercel](https://vercel.com/), e o deploy é feito automaticamente a partir do GitHub.

## Como editar

1. Faça alterações nos arquivos do repositório (`index.html`, `style.css`, etc.)
2. Suba (commit e push) para o branch `main` no GitHub
3. A Vercel detecta mudanças e publica automaticamente
